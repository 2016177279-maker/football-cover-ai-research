# Football Cover AI Research

Football Cover AI Research is an independent, non-commercial, nonprofit academic research project studying visual characteristics and engagement patterns in publicly available football-related video content.

> **Project policies:** [Privacy Policy](PRIVACY.md) · [Terms of Use](TERMS.md)

## Research Purpose

The project investigates how visual features of football-related video thumbnails or cover images may be associated with public engagement and content-performance indicators. Its purpose is academic research, statistical analysis, and validation of research methods.

The project is not a commercial SaaS product, does not sell YouTube API data, and does not provide advertising or paid services.

## Research and Analysis Workflow

The research workflow includes:

1. collecting publicly available football-related video metadata;
2. identifying relevant public football content;
3. examining publicly accessible thumbnails or cover images;
4. extracting structured visual features for research;
5. conducting statistical and comparative analysis; and
6. validating the research methodology and documenting findings.

## Use of the YouTube Data API

The project uses the YouTube Data API with an API key to retrieve public data needed for research. Depending on the research query, this may include:

- video IDs;
- video titles and descriptions;
- publication dates;
- public video statistics;
- public channel metadata;
- publicly accessible thumbnails;
- public search results used to identify research candidates.

API data is used only for academic research, statistical analysis, and research-method validation. The project does not use the API to modify YouTube content or act on behalf of YouTube users.

## Authentication and Data Scope

The project accesses public YouTube data with an API key. It does not support or require Google or YouTube account login and does not use OAuth to access user-authorized data.

The project does not obtain or store Google user passwords, OAuth credentials, private YouTube data, or other non-public Google user information.

## Data Handling

Public YouTube API data is handled according to the project's [Privacy Policy](PRIVACY.md), including the stated retention, refresh, and deletion practices. The project does not sell data obtained through the YouTube API or use it for advertising, user profiling, or commercial resale.
