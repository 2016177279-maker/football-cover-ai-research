# Privacy Policy

**Last updated: August 17, 2026**

Football Cover AI Research is an independent, non-commercial, nonprofit academic research project. This policy explains how the project uses information obtained through the YouTube Data API.

## YouTube API Services

The project uses the YouTube Data API with an API key to obtain publicly available data needed for research. The research covers publicly available video metadata and publicly accessible video thumbnails or cover images. Depending on the research query, public metadata may include video IDs, titles, descriptions, publication dates, channel information, public statistics, thumbnails, and public search results.

The project does not require members of the public to sign in with a Google or YouTube account. It does not use OAuth to access user-authorized data and does not obtain or store Google user passwords, OAuth credentials, private YouTube data, or other non-public Google user information.

The project does not collect personal information directly from end users.

## Purpose and Use

Data obtained through the YouTube Data API is used only for academic research, statistical analysis, and validation of research methods.

The project does not sell data obtained through the YouTube API and does not use such data for advertising, user profiling, or commercial resale. Football Cover AI Research is not currently a commercial software-as-a-service (SaaS) product offered to the public.

## Data Sharing

The project does not sell YouTube API data. Public research materials may describe research methods and aggregate or statistical findings. Any display or use of YouTube API data remains subject to the applicable YouTube API Services policies.

## Data Retention, Refresh, and Deletion

The project limits storage of public YouTube API data to what is reasonably necessary for the research. Public API data accessed without user authorization is deleted or refreshed no later than 30 calendar days after it is stored, in accordance with the YouTube API Services Developer Policies. The project uses reasonable efforts to keep stored and displayed API data consistent with current data available through the YouTube API Services and to identify historical observations as historical where applicable.

If API data is no longer available from YouTube, or if retaining it is no longer necessary for the research, the project removes it from active project storage as applicable. Requests concerning publicly displayed research materials may be submitted through the repository contact channel below. Deleting material held by this research project does not delete or alter information held by YouTube; requests to remove information from YouTube must be directed to YouTube through its own services and procedures.

Because the project does not use OAuth or access user-authorized data, it does not hold OAuth tokens or private account data for users to revoke or delete.
